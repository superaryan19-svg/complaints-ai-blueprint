# 12-Week Project Roadmap & Deliverables

**Client**: Kestrel Bank  
**Engagement**: AI Transformation Blueprint for Complaint Operations

| Week | Project Phase | Primary Objectives & Deliverables | Core Tools |
| :---: | :--- | :--- | :--- |
| **Week 1** | **A1: Define** | Problem Statement, Project Charter, SIPOC Process Map, CTQ Tree, Data ingestion script | Python (`pandas`), Markdown |
| **Week 2** | **A1: Measure & Analyse** | Baseline KPI Table, Pareto Analysis, 100-narrative qualitative tagging, Fishbone diagram & 5 Whys | Python (`seaborn`, `scikit-learn`), draw.io |
| **Week 3** | **A1: Improve & Control** | As-Is Process Map (with step tags), Catalog of 6 Non-AI Quick Wins, AI Opportunity Tags, Control Plan, A1 One-Pager PDF | draw.io, Markdown / PDF |
| **Week 4** | **A2: Financial Model Build** | Assumptions Register, Token Economics Unit-Cost Calculator, 3-Year Cash-Flow Model with Ramp-Up | Microsoft Excel (Desktop) |
| **Week 5** | **A2: Scenario & Sensitivity** | Worst / Base / Best Scenarios, 8-factor Tornado Sensitivity Chart, A2 Executive One-Pager | Microsoft Excel (Desktop) |
| **Week 6** | **A3: Value Dashboard** | Simulated 90-day pilot event log generator (64k rows), Star-Schema Data Model, 18+ DAX Measures, 4 Persona Pages (CFO, COO, CRO, Sponsor) | Python, Power BI Desktop, DAX |
| **Week 7** | **Flagship A: Framing & Discovery** | SCQ Engagement Framing, Issue Tree, Stakeholder Map, 30-min Interview Guide, Pain-Point Register | Markdown, Word |
| **Week 8** | **Flagship A: Process & Requirements** | To-Be BPMN (HITL Review checkpoints), AI-aware BRD, User Stories with Acceptance Criteria, Requirements Traceability Matrix (RTM) | draw.io / Visio, Markdown |
| **Week 9** | **Flagship A: Prioritization & Case** | Decision Ladder, 6-Criteria Use-Case Scorecard, Value vs Feasibility Matrix, Board Business Case Deck Slide | Excel, PowerPoint |
| **Week 10** | **Flagship A: AI Governance** | Indian Regulatory Control Map (DPDP 2025/2027, RBI FREE-AI 7 Sutras, RB-IOS 2026), Risk Register, RACI Matrix | Markdown, PowerPoint |
| **Week 11** | **Flagship A: Roadmap & Pitch Deck** | 12-Month Phased Implementation Plan with 3 Stage Gates, 10-Slide Action-Titled Executive Pitch Deck | MS Project / ProjectLibre, PowerPoint |
| **Week 12** | **Flagship A: Packaging & Review** | 2-Page Executive Case Study, Final Quality Review, STAR Interview Defense Stories, LinkedIn Post | Markdown, PDF |
